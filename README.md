# الصقر | AL-SAQR Food Supplies

واجهة عربية تجريبية لمتجر توريدات المطاعم والفنادق والكافيهات.

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
من إعدادات المستودع افتح **Settings → Pages**، ثم اختر **GitHub Actions** كمصدر للنشر. يوجد workflow جاهز داخل `.github/workflows/deploy.yml` للنشر عند التحديث على فرع `main`.

> هذه نسخة واجهة عرض (Frontend Preview). نموذج عرض السعر تجريبي وغير متصل حاليًا بخدمة استقبال طلبات، كما يجب استبدال روابط التواصل التجريبية ببيانات الشركة الرسمية قبل الإطلاق.
